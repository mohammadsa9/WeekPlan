# 📅 WeekPlan

A lightweight, front‑end only weekly planner that lets students compose and preview class schedules entirely in the browser—no backend required.

## 🌐 Live demo

GitHub Pages: [https://mohammadsa9.github.io/WeekPlan](https://mohammadsa9.github.io/WeekPlan)

## ✨ Features

- Frontend‑only app that runs entirely in the browser with zero backend dependencies for fast setup and privacy.
- Responsive layout with Bootstrap and clean iconography via Font Awesome for an accessible UI.
- jQuery‑powered interactions for concise DOM manipulation and instant UI updates.
- Student‑focused planner to build and visualize class schedules quickly.
- Add a single course across multiple days and time slots to reflect real timetables.
- Add exam date and time per course to centralize planning.
- Automatic detection of in‑class time conflicts across the weekly grid.
- Automatic detection of exam‑time conflicts to avoid overlaps.
- Local persistence in the browser for returning to saved schedules later.
- Edit existing class information without recreating entries.
- Share a read‑only schedule with others for quick viewing and collaboration.
- Export schedule to PDF (experimental) for printing and record‑keeping.

## 🧰 Tech stack

- HTML, CSS, JavaScript
  - Bootstrap (responsive layout)
  - Font Awesome (icons)
  - jQuery (DOM/events)

## 🔒 Data & privacy

All data is stored locally in the browser for simplicity and privacy.

**Note: Clearing site data or switching devices removes saved schedules unless exported.**
